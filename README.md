# PearlPop

Submarine survival game with five depths, Fish API shield challenges, a Workshop and SQLite accounts.

## Run

1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm ci`, then `npm start`.
4. Open http://localhost:3004/.

You can also use `start-windows.bat`.

Accounts and progress are stored in `data/pearlpop.sqlite`. Keep the data folder when updating.
